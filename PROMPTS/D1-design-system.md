# D1 · Lock the look

**Claude Design**

```
Create a design system for a low-poly browser driving game. Dark, clean,
developer-tool aesthetic. Night-time desert highway.

Visual language: flat-shaded low-poly, hard polygon edges, solid colour fills,
no textures, no image maps, no gradients on any surface.

Exact palette, use these values and nothing else:
  #0D1117  near-black, the sky and the far horizon
  #161B22  dark slate, the ground either side of the road
  #1C2128  asphalt, the road surface
  #30363D  edges, kerbs, and the low hills
  #E6EDF3  off-white, lane markings and HUD text
  #8B949E  grey, secondary HUD labels
  #F85149  RED — the player car, and every hazard

Red is the only saturated colour in the entire scene. The player car is solid
red. Hazards are off-white with red banding. Nothing else in the world gets red
at all.

Typography: Anton for numbers and headings. JetBrains Mono for small labels
and badges, uppercase with generous letter spacing.

Give me a swatch board, the type scale, and one sample HUD element so I can
see the system before we build anything.
```
