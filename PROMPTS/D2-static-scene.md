# D2 · The scene, static

**Claude Design**

```
Build a 3D scene using this design system. Static only, no animation.

Road: straight two-lane road running to the horizon, 8 metres wide, #1C2128
surface, dashed #E6EDF3 centre line and solid #E6EDF3 edge lines.

Camera: chase camera, 6 metres behind the car and 3 metres above it, angled
slightly down, 55 degree field of view.

Car: simple boxy low-poly vehicle, 4.2m long, 1.8m wide, 1.4m tall, in #F85149
with a #0D1117 window band and #30363D wheels. Centre of the road.

Roadside: #161B22 ground, low faceted hills and sparse angular trees in
#30363D. Sparse, not a forest.

Obstacles: three distinct low-poly types — a traffic cone, a road barrier, and
a stalled car. Bodies in #E6EDF3 off-white with #F85149 stripe banding, so they
read instantly against the dark asphalt but never get confused with the player
car, which stays the only solid red object on screen. Place one of each on the
road as a preview.

Lighting: one directional key light from the upper left, low ambient fill,
clean hard-edged geometric shadows. Night mood, but everything stays readable.

Name every group separately: road, roadside, car, obstacles.
```
